# 设计

## 目标

在任意应用里选中文字，一键加入微软拼音的个人词库；词库以 sqlite 为母库，
通过私有 Git 仓库跨设备同步；输入法那一侧只是投影产物，随时可重建。

## 三层结构

```
取词层            SelectionReader
                  UIA TextPattern -> 剪贴板兜底(Ctrl+C + 还原) -> 手动输入兜底
    │
母库层            PhraseStore (sqlite) + changes/<id>.<rev>.json (不可变变更文件)
    │             加词立即成功，不受输入法状态影响
    │
投影层            ImeDeployer
                  读现有文件 -> 合并 -> 排序 -> 序列化 -> 体检 -> 备份 -> 原子替换
```

三层各自独立失败：输入法没装、文件被占、同步断网，都不影响「词已经进了母库」。

## 数据模型

```sql
CREATE TABLE phrases (
  id         TEXT PRIMARY KEY,   -- 16 位随机串，跨设备稳定
  text       TEXT NOT NULL,      -- 词面
  code       TEXT NOT NULL,      -- 拼音编码，a-z 与 '
  rank       INTEGER,            -- 候选位 1..9
  enabled    INTEGER,            -- 是否投影进输入法
  source     TEXT,               -- selection / manual / cli
  created_at INTEGER, updated_at INTEGER,
  rev        INTEGER,            -- 递增版本
  deleted    INTEGER             -- tombstone
);
```

一个词条可以有多个编码（全拼 + 简拼），在库里是两条记录，共享同一个 `text`。

## 同步协议

**每次变更一个不可变文件**：`changes/<id>.<rev>.json`。

这样多设备同时加词只会新增文件，git 永远是「两边都新增」，不会产生内容冲突，
合并规则退化成两条：

1. 同 `id` 取 `rev` 大的
2. 删除是 tombstone（`op=delete`），优先于更低 `rev` 的更新

仓库里只有词条本身，不记录来源应用、窗口标题、剪贴板历史、文件路径。

代码仓库公开，词库仓库私有，两者不交叉。

## 部署六步

| 步 | 动作 | 失败处理 |
|---|---|---|
| 1 | 读现有 `.lex` 并解析 | 结构异常立即中止，不碰系统文件 |
| 2 | 与母库合并（母库优先，保留用户手工加的条目） | — |
| 3 | 按编码升序排序 | 排序是硬约束，单元测试覆盖 |
| 4 | 序列化到同目录临时文件 | — |
| 5 | 回读体检（魔数/偏移表/长度/字符集/候选位） | 体检不过放弃写入 |
| 6 | 备份 -> 原子替换 -> 落盘后再校验 | 校验不过自动回滚 |

## 交互

| 入口 | 状态 |
|---|---|
| 全局热键 `Ctrl+Alt+D` | v1 已实现 |
| 托盘菜单「加入选中的文字」 | v1 已实现 |
| 选区旁浮条 / `Ctrl+右键` | v2 计划 |

Windows 的 Shell 右键菜单只作用于文件系统对象，各应用文本框的原生右键菜单没有
第三方扩展点，所以「系统右键里多一项」只能做成自绘菜单或浮条，不能真插进别人的菜单。

## 已知硬约束

| 约束 | 值 | 来源 |
|---|---|---|
| 编码长度 | ≤ 32 字符 | 社区实现 + 本机实测 |
| 词面长度 | ≤ 64 字符 | 同上 |
| 候选位 | 1..9 | 字段 1 字节，UI 只给 9 个坑 |
| 母库投影软上限 | 2000 条 | 留足余量，硬顶约 2 万 |
| 生效时机 | 必须切换一次输入法 | 本机实测 |

长句（>64 字符）只进母库、不进输入法，托盘明确告知。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 微软更新改格式 | 部署前先解析现有文件；解析失败只写母库，不碰输入法 |
| 乱序 / 结构错导致整库失效 | 序列化后强制回读体检，排序写进单元测试 |
| 设置页卡死 | 软上限 2000 条，保留最近 N 份备份，一条命令还原 |
| 数据目录被改坏 | `tools/restore-ime.ps1 -Pristine` 按快照还原并校验哈希 |
| 隐私 | 私有仓库只存词条；不记录来源上下文；可加本地加密 |
| 输入法进程杀不掉 | 不尝试；提示用户切一次输入法 |
